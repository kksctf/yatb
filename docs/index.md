# YATB documentation

YATB is a yet another fast and furious jeopardy-CTF taskboard

## Features out-of-the-box

- Flexible auth system with OAuth2 support
- Flexible flags and scoring system
- OpenAPI schema and swagger UI - easy to integrate API
- Telegram notifications for the first bloods
- Dynamic tasks! In k8s!
- Blazing :) fast!

Read [Task files](tasks.md) to learn how to define declarative tasks.
Read the [release notes](release-notes.md) for changes by version.
The [archived documentation](old/index.md) describes older versions and contains outdated paths and instructions.
